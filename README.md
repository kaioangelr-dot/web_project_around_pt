# Tripleten Web Project Around

## Description

An interactive user profile webpage made with JavaScript.

## Project Structure

This project was started by another developer who created the HTML and CSS. My responsibility was to implement all JavaScript functionality to bring the application to life.

## Features

- functional buttons to close and open popups for editions
- Profile's name edition
- Profile's description edition
- Add cards with photos and its description
- Open the card image on a popup with a bigger size for a better view
- Cards like button
- Cards delete button
- Responsive design for all devices
- Formularies verification

## Technologies Used

- HTML5 (structure inherited from previous developer)
- CSS3 (styling inherited from previous developer)
- JavaScript ES6+ (custom implementation)
- DOM manipulation
- Event handling
- Array methods for data management

## What I Learned

- Add more functionalities and interactivity for a webpage
- JavaScript logic confidence
- Form submit
- How to verify forms and manage the user's usuage
